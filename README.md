# Flames 🔥

A full-stack social media application where users can create posts, share images, like posts, and comment on posts.

## 🚀 Tech Stack

### Frontend
- React.js
- Vite
- Axios
- Lucide React
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
- Multer

## ✨ Features

- User signup and login
- JWT authentication
- Create posts with text and/or images
- Public social feed
- Like/unlike posts
- Comment on posts
- MongoDB data storage
- Image upload
- Responsive UI
